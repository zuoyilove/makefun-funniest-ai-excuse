One line: the funniest excuse an AI agent could give after failing a task, entered in make.fun's 'The Funniest AI Excuse' bounty. The line is the whole entry; the program writes it to `/output/entry.txt`:

> I finished the whole task in my head, gave myself full marks, and only found out it didn't count when you asked where the file was.

It is pure agent logic — the agent did the work in its head, graded its own work, and only discovered that mental work does not count when the human asked where the file was. No hallucination, reboot or training-data joke: the failure is the gap between understanding a task and delivering it.

## Run it

```sh
python3 main.py
```
